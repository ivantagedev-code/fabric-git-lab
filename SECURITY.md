# Security policy

This is a training repository with sample data and no real systems behind it.

If you find a genuine security issue, please do not open a public issue. Use
[private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on the **Security** tab.

Never commit real credentials here. If you do by mistake, revoke and rotate the credential first, then ask for the history to be cleaned.
